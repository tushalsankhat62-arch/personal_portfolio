# Tushal Sankhat — Portfolio Website

A responsive React + Vite portfolio based on the supplied resume.

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP and open the `tushal-portfolio` folder in VS Code.
3. Open the terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite (usually http://localhost:5173).

## Customize before publishing
- Add your real project screenshots, descriptions, GitHub links and live demos in the Selected Work section.
- Add your LinkedIn and Instagram profile URLs when ready.
- Confirm internship dates, organization names and responsibilities before adding them.
- The portfolio currently uses the resume's email and general location. It intentionally does not publish your date of birth or phone number.
- The three work cards are placeholders, not claims that those projects are completed.

## Build for deployment
Run `npm run build`. Upload the generated `dist` folder to Vercel or Netlify, or connect the repository to Vercel.
